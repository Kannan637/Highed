PHASE 1 — LCP OPTIMIZATION
==================================================

Primary goal:

LCP <= 2.5s
Target ideal LCP <= 2.0s

Identify the actual LCP element using Lighthouse/Chrome DevTools.

Do NOT guess.

If the LCP element is the hero image:

1. Use next/image.
2. Use priority={true} only for the actual above-the-fold LCP image.
3. Add appropriate sizes.
4. Use responsive srcset generated by Next.js.
5. Use modern WebP/AVIF where supported.
6. Avoid unnecessary image transformations.
7. Avoid loading the same hero image multiple times.
8. Do not lazy-load the LCP image.
9. Preload only when genuinely beneficial.
10. Give the image explicit width/height or aspect-ratio.
11. Prevent layout shifts.

If the LCP element is text:

1. Optimize font loading.
2. Avoid render-blocking font requests.
3. Use next/font.
4. Load only required font weights.
5. Remove unused font families.
6. Use font-display appropriately.
7. Avoid JavaScript-dependent rendering of hero text.

Investigate:

- preload chain
- CSS dependency chain

- hero image request timing
- hydration delay
- client component rendering

PHASE 2 — NEXT.JS JAVASCRIPT OPTIMIZATION
==================================================

Reduce unnecessary client-side JavaScript.

Audit every "use client".

For every component:

ASK:

"Does this component actually require browser interactivity?"

If NO:
- convert it to a Server Component.

If YES:
- keep it client-side.

Avoid making entire pages client components just because
one child component requires interaction.

Move interactive logic into the smallest possible component.

Example:

BAD:

"use client"

export default function EntirePage() {
   ...
}

GOOD:

export default function Page() {
   return (
      <>
         <StaticContent />
         <InteractiveCTA />
      </>
   )
}

"use client"

function InteractiveCTA() {
   ...
}
